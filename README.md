A one-sentence pitch for the worst, most useless app imaginable: a premium subscription service that solves a problem nobody has — holding your place in a queue you are already standing in.

> QueueBuddy is a premium subscription app that reserves your place in queues you are already standing in, charging $4.99 a month to hold the spot directly behind you for a customer who will never arrive.

`main.py` (Python 3.13, standard library only) holds the pitch in the `ENTRY` constant, validates it with `validate()` — one string, 1–240 characters, no newlines, no leading/trailing whitespace, no control or format characters — then writes it to `/output/entry.txt` with no trailing newline. The output directory comes from `MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
